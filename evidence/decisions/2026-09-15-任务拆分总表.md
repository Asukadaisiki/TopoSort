## T1 基建：包骨架 + CI + 契约定稿 `infra`
- 骨架：`app/{models,events,scene,ui}/` 包结构（见 AGENTS.md），每个公共函数给签名 + `NotImplementedError` 存根
- CI：GitHub Actions，ubuntu+macos 矩阵跑 `uv sync && uv run pytest`；**契约测试先行（红）**：5节点标准图 → 6 条合法序、事件流确定性、导入 models 不得带入 PySide6、UI 全链路冒烟（offscreen）
- 契约：事件类型与字段、`parse()` 错误类型（带行号）、重复边/自环处理、泳道上限 K、输入/期望文件格式（`.in`/`.expected`）
- 验收：CI 在空跑存根上红得"指名道姓"（每条红测试对应一个模块）；文档补进 `evidence/decisions/`

## T2 算法内核 `core`（models/）
- `parser.py`：`<a,b>` 逐行解析；容错：空白行、全角括号、`a,b` 无尖括号（宽松接受）；错误报行号
- `graph.py`：节点/边容器（重复边去重、自环按契约）；`layers()` 最长路径分层
- `enumerator.py`：Kahn（显式栈回溯）全序枚举 + 生成器模式 + 仅计数模式；环检测返回卡住节点集
- 验收（全部走公共 API + test-data）：5节点标准图恰 6 条且全合法；`max_count` 截断行为；坏行报行号；30/60节点稀疏图极速模式耗时写入 benchmarks.csv；零 Qt 导入

## T3 事件引擎 `events`（events/）
- `player.py`：Graph → 确定性 StepEvent 流（Enqueue/Consume/Fork/Complete/DeadEnd/CycleFound）
- `timeline.py`：伪并发时间线：每 tick 交错推进所有活跃分支；暂停/单步/恢复/调速；泳道上限 K，溢出转后台计数
- 验收：同输入两次播放事件序列逐项相等；重放标准图事件流恰 6 次 Complete；时间线状态机转移全覆盖测试；零 Qt 导入

## T4 渲染场景 `scene`（scene/）
- `board.py`：消费 `layers()` 生成节点/边图元，平移缩放；`apply_event(event)` 更新视觉状态
- `effects.py`：渐隐幽灵、脉冲高亮、边淡化（QPropertyAnimation，时长常量集中管理）
- `pool.py`：候选池芯片动画；`export_png()`
- 验收（pytest-qt，offscreen）：喂脚本化事件序列后节点视觉状态断言正确；动画时长有界；PNG 导出非空；**每类效果 ≥1 截图入 evidence/screenshots/**

## T5 界面壳 `ui`（ui/ + main.py）
- 主窗口布局、输入面板（文本框/打开/保存）、控制条（速度/暂停/单步/跳完）、泳道面板、结果列表 + 导出 txt、错误对话框（解析错/环）
- 验收（pytest-qt offscreen）：粘贴→开始→结果出现全链路冒烟；文件打开/保存往返一致；两类错误弹窗文案断言；主窗口各状态截图

## T6 集成联调 `integration`
- 用真实 events 替换 T4/T5 的桩；接线 input→parse→player→timeline→scene→ui
- 全链路手工+自动回归；动画节奏调优（默认速度手感）；泳道数量在真实分叉下的布局
- 验收：CI 全绿 + 中期检查演示脚本彩排通过（9.20）

## T7 打包发布 `release`
- `tools/build.sh`：`uv run pyinstaller --onefile --noconsole`，linux-x64 与 macOS 各自本机构建
- 空目录启动冒烟、readme.txt（运行/构建说明）、zip 组装清单
- 验收：两平台单文件产物从空目录双击可跑；readme 按交付要求核对

## T8 交付文档 `docs`（并行，M3 齐）
