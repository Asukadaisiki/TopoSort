# 2026-09-15 技术栈定案：Python 3 + PySide6 + PyInstaller 单文件

- **状态**：已定稿（组长决策，组员异议期至 mid-check）
- **对应 Issue**：https://github.com/STU-MS/TopoSort/issues/1
- **日期**：2026-09-15 · **决策人**：组长（HandyWote）

## 背景

- 作业要求：非网页 GUI；`<a,b>` 输入 → 有向图渲染 → 输出尽可能多拓扑序；文本存储；环检测；平台不限、自己电脑验收。
- 组内开发机为 Linux + macOS；**但产品目标为三端通用（Windows / macOS / Linux），验收可能在 Windows 机器上进行，打包与测试必须覆盖 Windows。**
- 产品目标：单二进制双击即跑；文件/手工双输入；**计算过程动画**（节点消耗、队列变化、分叉多路伪并发泳道）；调速/暂停/单步；结果与图片导出。

## 已淘汰候选

| 候选 | 淘汰原因 |
|---|---|
| C# WinForms + MSAGL | GViewer 仅 Windows，无法覆盖三端目标 |
| C# Avalonia + AvaloniaGraphControl | 单文件已实测可行（48MB），但图重排无过渡动画、结构变更全量重建，做不出动态演化效果 |
| Java + GraphStream | 动态图原生，但 jpackage 出文件夹非单文件；力导向布局丢失分层语义 |

## 结论与理由

**Python 3 + PySide6（QGraphicsView）+ 算法自研 + PyInstaller --onefile。**

关键洞察：产品设计采用“固定分层布局 + 节点消耗渐隐”，不需要力导向重排，因此：
1. 分层布局自算 ≤40 行（层号=从源点最长路径，拓扑排序副产品），自动布局库不再必需；
2. QPropertyAnimation/QTimer 提供完全可控的动画（渐隐/脉冲/泳道分裂）；
3. Python + PySide6 本身三端原生支持；打包采用 PyInstaller 按目标平台各自构建（Windows 产物需在 Windows 上打包，或经 GitHub Actions windows-latest 自动产出）；**风险与对策：Windows 下需重点回归杀软误报（应对：优先用 GitHub Actions 官方环境构建产物、提交时附 SHA256 校验值）与首次启动解压慢（应对：文档写明，演示前提前启动）**；
4. 距提交约两周，Python 迭代速度占优。

## 影响范围

- 仓库结构（app/ 模块划分）见 AGENTS.md 第一节。
- 红线：算法（Kahn、全序枚举、环检测）必须自研，库仅用于 GUI 与打包。
- **三端兼容为硬性要求**：代码禁用平台专属 API（文件路径用 `pathlib`，编码显式 UTF-8，回车换行用 `newline=''` 处理），CI 矩阵覆盖 ubuntu / macos / windows。
